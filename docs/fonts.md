# Fonts

Status: **no fonts are bundled yet** (the reader is Phase 3).

Rules (Principle 13, SRS §48, RISK_REGISTER R-24):

- Only **Unicode** Gurmukhi fonts. Legacy ASCII-encoded fonts (AnmolLipi and most "Hastlikhat"
  faces) require a lossy text-to-glyph re-encoding that contradicts byte-exact preservation and are
  excluded on integrity grounds even where licensing would allow them. The original request for
  those faces stands recorded in Q1 §D.
- Only fonts with an open, redistributable licence suitable for web embedding (OFL, Apache-2.0, or
  equivalent). Record for each: name, version, licence, licence URL, source URL, date checked.
- Candidates to audit: Noto Sans Gurmukhi, Noto Serif Gurmukhi, Mukta Mahee, Lohit Gurmukhi, Saab,
  and any open-licence handwritten-style Unicode faces that can be found.
- Hindi/English/Urdu companions for translation panes (Q1 §D) follow the same rules.
